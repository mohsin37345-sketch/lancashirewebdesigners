# Local & Industry Link Building Playbook

## Overview
Backlink authority remains a core ranking signal for competitive commercial search terms such as `bespoke web design` and `b2b web design agency`. This document establishes an ethical, white-hat link acquisition framework for Lancashire Web Designers, strictly adhering to Google Search Essentials and avoiding spam networks, PBNs, or low-quality link-purchasing schemes.

## 4. Anchor Text Diversity Guidelines

To maintain a natural, non-manipulative backlink profile, adhere to strict anchor distributions:

| Anchor Type | Target Proportion | Examples |
| :--- | :--- | :--- |
| **Branded** | 50% – 60% | `Lancashire Web Designers`, `lancashirewebdesigners.co.uk` |
| **Naked URL** | 20% – 25% | `https://www.lancashirewebdesigners.co.uk/` |
| **Generic** | 10% – 15% | `visit website`, `click here`, `source`, `our website` |
| **Exact / Partial Keyword** | 5% – 10% | `bespoke web design Lancashire`, `Preston web design agency` |

*Critical Warning*: Never exceed 10% exact-match commercial anchor text across external backlinks. Excessive commercial anchors trigger Google algorithmic link-spam filters.
